# 衛星の画像の出典

すべて NASA の画像ライブラリ（https://images.nasa.gov/）から取得（2026-09-30）。縮小しただけで、切り抜きや色の加工はしていない。
5枚とも目で見て、人物・ロゴ・透かしが写っていないことを確かめた（2026-09-30）。

**このサイトは広告を載せる前提**（2026-09-30 オーナー判断）。商用でも使える画像だけを入れる。

## 利用条件（2026-09-30 に読んだ）

- NASA（https://www.nasa.gov/nasa-brand-center/images-and-media/）：原則として著作権の対象外。出典として NASA を示す。NASA が推薦しているように見せない。ロゴは使わない。他者が著作権を持つ素材は著作権者名つきで明示されるので、その場合は個別に確認する。見分けのつく人物が写るものを商用に使うときは本人の許可が要る
- JPL（https://www.jpl.nasa.gov/jpl-image-use-policy/）：事前の許可なく使える。出典の書き方は「Courtesy NASA/JPL-Caltech」。NASA・JPL・Caltech の推薦に見せない。ロゴは使わない
- 商用利用について（上の2つのページの記載）：NASA・JPL とも、商品やサービスを NASA が推薦しているように見せないこと、見分けのつく人物が写るものは本人の許可を取ること、他者が著作権を持つ素材は著作権者に確かめること、が条件。**広告を実際に載せる前に、両方の「商用利用」の項をもう一度読む**

## 気をつけること

- テラは、出典に個人名とプロジェクト名（NASA の研究所 JPL の Solar System Visualization Project）が入っている。ライブラリの記録に著作権者の明示はないので使っている。広告を載せる前に、もう一度確かめる
- アクアは所属が JPL だが、ライブラリの出典は「NASA」だけ。記載どおり「NASA」と出している

## 使わなかったもの

- ACS3・ソーラーセイル（ACS3_SolarSailPush_001、出典「NASA/Aero Animation/Ben Schweighart」）：出典に会社名が入っていて、権利が NASA にあるか記録から断定できない。広告を載せる前提なので外した（2026-09-30 オーナー判断）。NASA に確かめられたら戻せる

- SERT 2（GRC-1968-C-03031）：地上試験の写真で、顔の分かる人が2人写っているため見送った
- OAO 2・OAO 3（コペルニクス）・オーブビュー2：ライブラリに衛星そのものの画像が見つからなかった
- JAXA の衛星（あじさい・だいち・だいち2号・みどりII・ひとみ・XRISM）：利用申請が要る見込み。広告を載せるサイトでの利用条件（有償になるか）も申請のときに確かめる
- ESA の衛星（エンビサット・ERS-1）：ESA のサイトの画像は商用利用不可。広告を載せる前提なので使わない
